# 2026-W46 (9 – 15 Nov 2026, plus Monday 16th)

## Built — code
- **Eyes wiring in the firmware:**
  - Each eye now has its own pins, and the right eye is on SPI1 (D-026), so
    `panels.py` drives two buses and each panel resets itself.
  - There wasn't room to reach GP17, so the left eye's CS went to GP22.
    The unconnected backlight PWM moved from GP22 to GP16 to make way
    (R-206 now says to wire BLK to GP16).
  - The panels are mounted a quarter-turn round. The screen driver gained
    a `rotation` option, done by the panel itself, so the drawing code is
    unchanged: left 270°, right 90°.
- No other code this week. 293 tests pass.

## Built — physical
- **Eyes done (R-202):** soldered straight to the boards with solid-core
  wire, both working, mounted on the eye plate, and the plate is bolted into
  the head. They're the first face part in the head for good.
- **Mouth panel printed (R-210):** the first print's bolt holes were in the
  wrong place, so it was reprinted.
- The eye plate drawing and the eye bracket model went into `anatomy/eyes/`.

## Decided
- **No mood on the mouth** (Henry's choice). R-210's "done when" now says a
  flat line when quiet.
- **Each eye gets its own pins, with the right eye on SPI1** (D-026), so the
  solid-core wire needs no mid-wire splices.
- **The left eye's CS is GP22** and the backlight PWM is GP16. This is wiring
  detail, so it's in `anatomy/eyes/build.md`, not a decision record.
- **The quarter-turn mounting is fixed in firmware**, not by re-mounting
  the panels.
- Dan approved all the waiting Henry-facing text: the eye plate, the four
  head CAD frames and the mouth summary.
- **Phase 7 grill (hands):**
