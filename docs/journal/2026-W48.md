# 2026-W48 (23 – 29 Nov 2026, reviewed Thursday 26th)

## Built — code
- **R-110 done (23 Nov):** each session's long-term memories now have
  fixed ids (`<session_id>-<n>`), and re-running rest on a session
  replaces them (`LongTermMemory.replace_session`). New tests against real
  SQLite and ChromaDB, with a fake embedding so no model is needed: rest
  during a conversation, two rests at once, and a re-rest after a crash.
  313 tests pass.
- **Memory design review with Dan (23 Nov):** four new ideas, all left as
  ideas unless needed:
  - R-112: the medium-term summary off the reply path;
  - R-113: memories that don't repeat and know what's recent;
  - R-114: long-term memories in `robot.db` instead of ChromaDB;
  - R-115: rest merges related memories.

  Also a new R-311 task: keep each person's facts separate before Henry's
  sister starts talking to Qbot.

## Built — physical
- **Waveshare USB TO AUDIO (R-306, bought 23 Nov, tested 25 Nov):** both
  speakers play through it, and the laptop sets its volume with `amixer`.
  At −20 dB it's already louder than the R30 board at power-on. This model
  has **no trim screw**. Notes in `anatomy/head/build.md`.
- **Speaker boxes printed** (~5 × 5 × 7 cm). The speakers aren't fitted yet.
  The size trial was dropped: it's only for a voice. They'll be stuffed with
  fluffed-up yarn.
- **Speaker panels** are printing now.
- **Mounting against vibration:** the crown and the speaker boxes get rubber
  on both sides of each mounting tab, with the bolt clear of the hole. Each
  crown mic gets a foam ring sealing it to its hole (R-302).
- **USB hub** bought and working (R-213). Where it mounts waits on the
  speaker boxes.
- **Antenna printed** (R-211) and approved by Henry. It still needs the
  adaptor that holds it inside the head.
