# 2026-W41 (5–11 Oct 2026)

## Built — code
- **Eyes: an expression for every mood at intensities 1–3** (R-203). Calm,
  curious, excited and scared are placeholder art until Henry draws them
  (R-204).
- After the first simulator run: curious redone (the one-eyed squint looked
  like a bug), sleepy redone (heavy curved lid, nods off at 2–3), sad
  redone (lid droops to the outer corner, tear wells at 2 and runs at 3).
  Serious, singing and zombie are commented out with TODOs (R-205).
- **Eyes wire format** (D-001): short ASCII lines, direction and
  expression sent independently or together. `main.py` on the Pico is now a
  command listener; the old wiring test moved to `bringup.py`.
- **Framebuffer drawing** (D-002): one SPI write per eye, no flicker.
  **Not yet tested on the Pico** (R-201).
- Simulator: intensity buttons and a command box that takes wire-format lines.

## Decided
- Brain computer is the hub; the router is its own process (D-003).
- Crown: build it ourselves on a Pico 2 with four I2S mics — two front
  stacked for height, one left, one right (D-004). One USB device with
  audio + serial (D-005). Direction maths in Python first (D-006). Skip the
  interim USB mic and go straight to four mics.
- Indicator LEDs are driven by the hardware they report on (D-007).
- The brain sends only a mood; the router composes the face (D-008).
- One Pico per organ (D-009).
- Wake button on top; asleep = mics and cameras off; answers everything
  while awake for now (D-010).
- Phases restructured around the build order: head with brain first, then
  body, then hands. "Head build" is no longer a separate phase — parts get
  mounted as they're developed.
