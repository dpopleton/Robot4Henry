# 2026-W45 (2 – 8 Nov 2026)

## Built — code
- **Eyes on the real Pico (R-201):** the first side-by-side run with the
  simulator froze some expressions. MicroPython's `math` has no `hypot()`,
  which `dead` and `scared` use at intensity 2–3. Swapped for `sqrt`, with a
  test that firmware only uses `math` functions MicroPython has. The
  simulator now shows the Pico's errors, so a crash isn't a silent freeze.
  Dan then checked every mood at every intensity on the real screens: all good.
- **Mouth (R-210), steps 1–3:**
  - shared Pico code in `organs/pico_common/` (framebuffer, line reader)
  - crash-watch in `nervous_system/pico_console.py`
  - `organs/deploy.py` to copy an organ's firmware to its Pico
  - the mouth firmware: a flat line when quiet, and a mouth-shaped
    seismograph while talking, driven by levels from the laptop (D-024)
  - the host driver
  - Timed on the eyes' Pico 2: about 80 ms a frame (12.5 frames a second).
- **Virtual robot started (R-209, D-023):**
  - `python -m virtual_robot --only mouth` is the mouth bench, with an
    Off/Virtual/Real/Both switch per organ.
  - "Say it" speaks in Qbot's Piper voice, moves the mouth from that audio,
    shows subtitles, and has a Sync slider for lip-sync.
  - Piper sometimes puts ~1.6 s of silence before a sentence, so the bench
    trims it (R-307 will need the same).
- **R-111 done and committed** with the W44 docs. 293 tests pass.
- `docs/disk-space.md` added.

## Decided
- **Qbot drives himself**, on voice commands or wandering; a gamepad is only
  for testing (D-020). Phase 5's "done when" says so now.
- **Ten wire colours:** 5V gets orange, and every eyes wire has its own
  colour (D-021, replaces D-019).
- **No Dupont anywhere:** wires inside an organ are soldered straight to the
  boards, and organs join the hub by USB (D-022).
- **One virtual robot app** built from per-organ panels; `--only <organ>`
  bench mode replaces `simulate.py` (D-023).
- **The laptop sends the mouth its voice levels**; the mouth Pico doesn't
  listen for sound itself (D-024).
- **Phase 6 grill (vision):**
  - The camera goes in a 2.5 × 10 cm insert above the Q, and moves into
    Phase 4 so it's in the head before the skin (R-601).
  - Its video LED runs off its own 5V, so "off" means no power, switched by
    the hub or a Pico (D-025).
  - The first task is who's talking (R-311) or objects, decided later.
    Face-following is dropped.
  - Try it on the current laptop before upgrading. Storing photos is fine.
  - Phases 5 and 6 may run in parallel; the order is decided at the time.
- Dan approved the Henry-facing summaries for the crown, eyes, head and
